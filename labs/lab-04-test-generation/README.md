# Lab 04 — Test Generation Factory

## Objective

Apply TDD with Copilot as your test-writing partner. You will define interfaces,
generate comprehensive tests before implementation, and then drive the implementation
to make tests pass.

---

## Part A — TDD Session (45 min)

### Target: Inventory Management Module

You will build an `InventoryService` using TDD. Write the interface first:

```python
# src/inventory/service.py
from dataclasses import dataclass
from uuid import UUID

@dataclass
class Product:
    id: UUID
    name: str
    sku: str
    stock_level: int
    reorder_point: int

@dataclass  
class StockAdjustment:
    product_id: UUID
    quantity: int  # positive = add, negative = remove
    reason: str

class InventoryService:
    """
    Manages product inventory levels.
    
    Operations:
    - get_product(product_id: UUID) -> Product | None
    - adjust_stock(adjustment: StockAdjustment) -> Product
      - Raises InsufficientStockError if result would go negative
    - get_low_stock_products() -> list[Product]
      - Returns products where stock_level <= reorder_point
    - reserve_stock(product_id: UUID, quantity: int) -> bool
      - Returns True if reserved, False if insufficient stock
      - Reserved stock is locked, not permanently deducted
    - release_reservation(product_id: UUID, quantity: int) -> None
    - commit_reservation(product_id: UUID, quantity: int) -> Product
      - Permanently deducts reserved quantity
    """
```

### Step 1: Generate Tests (BEFORE implementation)

Open Copilot Chat with the file above open:
```
/tests Generate a comprehensive pytest test suite for InventoryService.
Tests must:
- Mock the data repository (InventoryService will accept a repository dependency)
- Cover every method including error paths
- Test the reservation system: reserve → commit, reserve → release
- Test concurrent reservation race conditions
- Use factory_boy for Product test data
Place tests in: tests/inventory/test_inventory_service.py
```

### Step 2: Run Tests — Expect All Failures

```bash
pytest tests/inventory/ -v
# Expected: all tests fail (service not implemented yet)
```

### Step 3: Implement to Pass Tests

```
Now implement InventoryService in src/inventory/service.py to make all 
the tests you generated pass. Do not modify the tests.
```

### Step 4: Verify Coverage

```bash
pytest tests/inventory/ --cov=src/inventory --cov-report=term-missing
# Target: ≥ 90% coverage
```

## Part B — Mutation Testing (30 min)

### Install and Run mutmut

```bash
pip install mutmut
mutmut run --paths-to-mutate=src/inventory/service.py --tests-dir=tests/inventory/
```

### Analyse Survivors

```bash
mutmut results
mutmut show <id>  # Show what mutation survived
```

### Ask Copilot to Kill Surviving Mutations

In Copilot Chat:
```
These mutations survived my test suite (my tests did not catch them):

[paste mutmut results]

For each surviving mutation, explain:
1. What the mutation changed
2. Why my current tests missed it
3. A new test case that would kill this mutation

Then generate all the new test cases.
```

### Re-run After Adding Tests

```bash
mutmut run --paths-to-mutate=src/inventory/service.py --tests-dir=tests/inventory/
# Target: Mutation score ≥ 80%
```
