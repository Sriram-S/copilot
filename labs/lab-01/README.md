# Lab 01: Your First Copilot-Generated Test

## Objective
Experience how Copilot generates test code from a simple prompt in both VS Code and IntelliJ IDEA.

## Duration
30 minutes

## Prerequisites
- GitHub Copilot extension installed and authenticated in VS Code **or** IntelliJ IDEA
- Node.js 18+ installed

## Setup

```bash
# Create a new directory for this lab
mkdir copilot-lab-01 && cd copilot-lab-01
npm init -y
npm install --save-dev jest @types/jest ts-jest typescript
npx tsc --init
```

## Exercise 1: Generate a Test from a Comment

### Step 1: Create a source file

Create `src/calculator.ts`:

```typescript
export function add(a: number, b: number): number {
  return a + b;
}

export function subtract(a: number, b: number): number {
  return a - b;
}

export function multiply(a: number, b: number): number {
  return a * b;
}

export function divide(a: number, b: number): number {
  if (b === 0) throw new Error('Cannot divide by zero');
  return a / b;
}
```

### Step 2: Start a test file with comments

Create `src/calculator.test.ts` and type ONLY the following (then let Copilot complete):

```typescript
import { add, subtract, multiply, divide } from './calculator';

describe('Calculator', () => {
  describe('add', () => {
    // Test: adding two positive numbers returns their sum
    
    // Test: adding a positive and negative number
    
    // Test: adding zero to a number returns the same number
    
  });
```

**Observe:** After each comment, press Enter and wait for Copilot's ghost text. Accept with `Tab`.

### Step 3: Use the `/tests` command

1. Select the entire content of `calculator.ts`
2. In Copilot Chat, type: `/tests`
3. Observe what Copilot generates
4. Compare to what you wrote manually

## Exercise 2: Generate Tests in IntelliJ (Java)

### Step 1: Create a Java Calculator class

Create `Calculator.java`:

```java
public class Calculator {
    public int add(int a, int b) { return a + b; }
    public int subtract(int a, int b) { return a - b; }
    public int multiply(int a, int b) { return a * b; }
    public double divide(int a, int b) {
        if (b == 0) throw new ArithmeticException("Cannot divide by zero");
        return (double) a / b;
    }
}
```

### Step 2: Use Alt+Enter to Generate Tests

1. Place cursor inside the class
2. Press `Alt+Enter` (macOS: `Option+Enter`)
3. Select "Generate Tests with Copilot"
4. Review the generated test class

## Reflection Questions

1. What context did Copilot use to generate consistent tests?
2. Did you need to accept every suggestion, or did you modify some?
3. What was the quality difference between comment-driven and `/tests`-driven generation?
